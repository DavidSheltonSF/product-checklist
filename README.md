# Product Checklist

Aplicativo Expo para manter um catálogo de produtos reutilizáveis e organizar uma coleta ativa. Cadastre produtos sem informar quantidades; ao adicioná-los à coleta, defina a quantidade necessária e acompanhe o progresso.

## Executar

```bash
npm install
npx expo start
```

Produtos e coleta ficam salvos localmente no dispositivo. Limpar a coleta remove apenas os itens e o progresso da coleta ativa; o catálogo e as fotos dos produtos são mantidos.
